# Demo checklist

1. `docker compose up --build`
2. Open `http://localhost:8000/docs`
3. Generate telemetry from the ingestion API.
4. Query telemetry and health.
5. Evaluate alerts.
6. Open Neo4j at `http://localhost:7474`.
7. Explain MongoDB, Redis, Cassandra and Neo4j access patterns.
8. Later demonstrate Terraform and Azure deployment.
